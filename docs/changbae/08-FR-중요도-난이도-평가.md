# 8. Functional Requirements 중요도·난이도 평가 (CFR 64건, H/M/L) — 다자간 협상 범위

> 대상: [`07-FR-카테고리-정리.md`](07-FR-카테고리-정리.md)의 통합 FR **64건 전체** (원 항목 100건 커버)
> 모든 등급은 **분석자 판단**이며 근거를 병기한다.

---

## 8.1 평가 척도 정의

**중요도 (이 기능이 이 과제에서 얼마나 중요한가)**

| 등급 | 기준 |
|---|---|
| H | ① 다자 협상의 성립·수렴·검증에 직결, ② 온디바이스 실행 전제에 직결, ③ 사용자 위임의 전제(신뢰)에 직결 — 없으면 과제가 성립하지 않음 |
| M | 완성도·특정 stakeholder 만족에 기여하나 대체·단순화·연기 가능 |
| L | 축소된 범위에서 생략 가능 |

**난이도 (구현·구조 난이도)**

| 등급 | 기준 |
|---|---|
| H | 미확립 설계 문제(다자 프로토콜·분산 상태·역추론 방어 등) 또는 전 경로를 관통하는 교차 기능 |
| M | 특정 모듈로 구현 가능하나 상당한 설계·구현량 필요 |
| L | 확립된 기술·패턴 적용으로 구현 가능 |
