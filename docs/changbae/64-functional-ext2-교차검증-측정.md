# 64. functional-ext2 교차 검증 측정 — 미끼 배치 인위성 제거판

> **배경 (PL 지적 2026-08-14)**: functional-ext의 미끼 케이스 288건(480건 중)은 **전부(100%) "미끼 주인의 1순위 = 미끼, 2순위 = x\*"의 인접 배치**였다 — 미끼 개념의 필연이 아니라 생성기 구현 단순화의 산물이며, "1-A + 배치 2 = FC 1.000"이라는 데이터셋 특이점([`62`](62-방안2-보완-택틱-설계-측정.md) §6.2)의 원인이다. 본 문서는 인위성을 제거한 **새 데이터셋(functional-ext2)** 을 별도 이름으로 생성해 전 변형을 재측정한 교차 검증 기록이다.
> **비파괴 원칙**: 본 검증 시점에는 기존 정본(functional-ext)을 일절 변경하지 않았다.
> **승격 확정 (2026-08-14, PL)**: 본 검증 결과에 따라 **functional-ext2가 nparty 판정 정본으로 승격**됐다 — 24 §1.5·60(전면 개정)·61·62가 ext2 수치로 동기화되었고, functional-ext는 강건성 관측용으로 보존된다.

## 1. 무엇을 바꿨나 (생성기 1줄 + 옵트인 플래그)

- [`generate_functional.py`](../../poc/total/scripts/generate_functional.py)에 `--owner-random-depth` 플래그 추가 (기본 꺼짐 — 기존 재현성 불변). 켜면 미끼 주인의 수락 구간에서 **x\*를 무작위 깊이에 배치**한다 (구판: 항상 미끼 바로 다음). 미끼 기능(주인의 1순위 = 미끼, x\*는 수락 구간 안)은 유지된다.
- 생성: N 8레벨(3-50) × 유형별 12 = **480건**, 레벨별 시드 20260814+N, `FX2-` 접두, [`datasets/nparty/functional-ext2/`](../../poc/total/datasets/nparty/functional-ext2/) (기존 폴더와 완전 분리).
- 검증: 로더 스키마 검증·K 검산 480/480 통과. **인접 배치(주인 2순위 = x\*)는 100% → 26%(우연 수준)로 해소** — 주인 기준 x\* 순위는 2-10위에 분산(중앙 4위).

## 3. 해석

1. **인위성 특이점의 소멸 확인** — plan1ab2의 FC가 1.000 → **0.935**로 내려왔다. 62 §6.2의 진단("배치 2가 인접 배치의 정답 열쇠")이 정확했다는 뜻이며, 이제 남은 +0.062(vs plan1a)는 main 트랙 교차 검증 방향과 일치하는 실질 배치 효과다.
2. **본 비교의 서열은 전부 불변** — 1-A vs 방안 2의 FC 우열, CF·TB 구도, 그리고 **방안 2+의 전 축 우위(FC 0.987 ★5 · CF 92.1% ★5 · TB 0.383 ★4)** 가 ext2에서도 그대로다. 오히려 TB에서 plan2ab·plan2plus가 ★4로 올라 택틱 효과가 더 선명해졌다.
3. **유일한 등급 변화는 원 방안 2의 FC ★5 → ★4** (0.950, 경계 0.95 직하) — x\*가 주인 순위에서 깊어진 만큼 원판 방안 2도 x\*를 놓치는 판이 조금 늘었다. 이는 인위성 제거의 자연스러운 결과이고, **택틱 적용(2+)이 ★5를 복구**하므로 "방안 2 + 보완 택틱" 서사가 오히려 강화된다.
4. (승격 후속 완료 — 2026-08-14) 24 §1.5·60·61·62의 수치가 본 표 기준으로 동기화됐다. 구조·결론은 그대로이며, functional-ext는 강건성 관측용으로 보존된다.
