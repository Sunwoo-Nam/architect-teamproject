# 11. 핵심 FR ↔ 핵심 QA 매핑

> 대상: **최우선 FR 9건** ([`04`](04-FR-중요도-난이도-평가.md) §4.6)과 **최우선 QA — QA ID 기준 15개 항목 + QA-FC-2** ([`08`](08-핵심-QA-중요도-난이도-평가.md) §8.3, 측정 정의는 [`10`](10-핵심-QA-측정-계획.md)).
> 매핑의 의미: **FR은 QA의 실현 수단**(그 기능이 있어야 그 품질이 달성됨)이고, **QA는 FR의 품질 기준**(그 기능이 어느 수준으로 동작해야 하는가)이다. ADR 작성 시 FR의 설계 대안은 매핑된 QA의 지표([`10`](10-핵심-QA-측정-계획.md))로 평가한다.

---

## 11.2 FR → QA 상세 (최우선 FR 9건 기준)

| CFR | 매핑 QA와 관계 설명 |
|---|---|
| **B2** 다자 협상 라운드 실행 | **SC-1 ●**: 라운드 제어 방식(순차/동시 수집)이 참여자 수에 대한 시간·메시지 증가 함수를 결정. **TB-1 ●**: 라운드 수 × 라운드당 시간이 곧 합의 도달 시간. **FT-1 ○**: 라운드 타임아웃 처리가 일시 결함의 투명 처리를 좌우. **OP-1 ○**: 개입 반영 시점이 라운드 경계 설계에 의존 | |
| **D3** 사용자 즉시 개입 | **OP-1 ●**: 개입 반영 지연·개입 후 상태 일관성의 직접 실현 수단. **FC-1 ○**: 비결정 계층(L1·L3) 오류의 최종 안전판 — "틀린 채로 확정되지 않는다" | |
| **G3** 참여자별 차등 정보 공개 | **CF-1 ●**: 공개 정책 위반 0건의 직접 실현 수단. **CF-2 ○**: 공개량 축소가 역추론 표면도 줄임 (단, 역추론 방어의 주 수단은 G5) | |
| **I7** 교착·폭주 감지 및 안전 종결 | **Fail Safe(목록 외) 주 대응**: 불확정 상태 0건의 실현 수단. **FT-1·FT-2 ○**: 결함이 교착으로 악화될 때의 최종 방어선. **SC-1 ○**: 무한 루프 차단이 수렴 실패의 안전망 | |
| **I8** 그룹 세션 복구·재동기화 | **RE-1 ●**: 복구 성공률·복구 후 상태 일치의 직접 실현 수단. **CX-1 ○**: OS 강제 종료(Doze·저메모리) 후 세션 생존이 복구 능력에 의존 | |
| **J2** Mock 다자 협상 시뮬레이션 | **TE-1 ●**: Mock 재현 커버리지의 직접 실현 수단. **전 QA의 측정 기반**: [`10`](10-핵심-QA-측정-계획.md)의 ENV-A가 J2(+J8) 위에 성립하므로, 매트릭스의 세로 전체가 이 기능의 존재를 전제한다 | |
| **B8** 양보(concession) 전략 | **SC-1 ●**: threshold 완화 속도가 수렴 라운드 수를 결정 — 양보 없으면 무한 루프. **FC-1 ○**: 과도한 양보는 선호 정합(L3)을 훼손 (수렴 vs 품질 트레이드오프). **FC-2 ○**: 참여자 간 양보 속도 차이가 효용 편향을 만듦. **TB-1 ○**: 수렴 라운드 수가 합의 시간의 지배 항 | |
| **B9** 합의 완결 규칙 실행 | **OC-1 ●**: 어떤 완결 규칙이든 미승인자 확정 효력 0건을 보장하는 지점. **FC-1 ●**: 합의 종결 정합(L4) — 확정 당사자 전원 동일 레코드의 판정 지점. **FC-2 ●**: 집계 규칙의 성질이 효용 분배 편향을 좌우 — QA-FC-2가 완결 규칙 설계 대안의 평가 기준. **FT-2 ○**: 참여자 상실 시 완결 규칙 재적용이 잔여 그룹 지속의 조건. **AD-1 ○**: 완결 규칙을 시나리오별로 구성 가능하게 만드는 것이 시나리오 가변성 수용의 일부 |
| **B12** 탐색 공간 축소 | **SC-2 ●**: 의제 조합 증가 함수 통제의 직접 실현 수단 (가지치기·지연 생성). **RU-1 ●**: 전체 열거 회피가 메모리 예산 준수의 조건 (PL 지목: out of memory). **TB-1 ○**: 후보 생성·평가량 축소가 라운드당 시간을 단축 | |

## 11.3 QA → FR 역방향 커버리지 (최우선 15개 항목 + QA-FC-2 + 기반 2개 기준)

각 QA를 실현하는 FR을 최우선 9건 안/밖으로 구분한다. "목록 외" FR도 전부 [`03`](03-FR-카테고리-정리.md)의 CFR이다.

## 11.4 관찰 (분석자 판단)

1. **최대 결합점은 B9(완결 규칙)** — 주 실현 관계만 3개 QA(OC-1·FC-1·FC-2)에 걸리고 FT-2에도 영향. 완결 규칙의 설계 대안 선택이 가장 넓은 품질 파급을 가지므로 ADR 1순위 후보다.
2. **J2(+J8)는 판 전체의 전제** — 특정 QA의 실현 수단이라기보다 모든 QA의 **측정 가능성** 그 자체다. 구현 순서상 가장 먼저 갖춰야 할 기능이다.
3. **커버리지 공백과 그 처리**: QA-CX-1(공존성)은 최우선 FR 9건만으로는 실현되지 않고, QA-FT-2·CF-2·OC-1·TE-1·RU-1도 주 실현 수단의 일부가 목록 외에 있다 — 최우선 FR 선정 기준이 "빈도 × (H,H)"이지 QA 커버리지가 아니기 때문이다. 해당 목록 외 FR 중 **(H,H)인 6건 — B11 · I10 · G5 · I14 · I16 · J8** — 은 매핑된 QA를 경유해 설계 논의에 반드시 포함해야 한다 (사실상 ADR 대상은 최우선 9건 + 이 6건 = 15건). QA-AD-1(적응성)의 주 실현 수단인 CFR-I3(프로세스 템플릿, H/M)도 설계 질문 9(시나리오 가변성)를 통해 ADR 논의에 함께 포함한다.
4. **양보 전략(B8)은 트레이드오프의 결절점** — 같은 FR이 SC-1(수렴)을 높이면서 FC-1(L3 품질)·FC-2(편향)를 해칠 수 있는 유일한 매핑 구조로, [`10`](10-핵심-QA-측정-계획.md)의 전략 비교 실험(CFR-J6)에서 세 지표를 반드시 동시 측정해야 한다.
