# 29. Confidentiality (기밀성 — 역추론 방지) — 정의 · 측정 방법 · 측정 목표

> 지위: Confidentiality는 **비핵심 QA(7위)**다 — 설계 대안 선정의 1차 축이 아니라 **보조 관측**으로 유지한다 ([`23`](23-핵심-QA-최종-확정.md) §23.3). 그럼에도 측정을 문서화하는 이유: PoC 측정 대상 5종에 포함되었고(PL 지시, 2026-08-11), 참여 사용자·Security 담당의 1순위 우려에 수치로 답할 자료가 필요하기 때문이다.
> 본 문서가 이 QA 측정의 정본이며, [`21`](21-핵심-QA-측정-정의.md) §21.3-9·§21.5-9를 대체한다 (공격자 구현 방식 변경 포함 — §29.4).
> 측정 수행 시 단일 참조: [`29-1 QA 측정 핸드북`](29-1-QA-측정-핸드북.md) — 본 문서는 지표·척도의 정의와 도출 근거를 담는다.

---

## 29.1 정의 (한 문장)

> **Confidentiality = 협상 중에 오간 것을 관찰하는 것만으로는, 다른 참여자가 무엇을 가장 원하는지 알아낼 수 없는가.**

프로토콜상 Ufun 점수는 전송되지 않는다. 그러나 제안·수락/거절의 **패턴** 자체가 정보를 흘린다 — 무엇을 언제 제안했고 무엇에 O를 줬는지를 모으면 선호가 복원된다. 이 축은 그 유출의 크기를 잰다.

## 29.2 용어

| 용어 | 뜻 |
|---|---|
| **관찰자(observer)** | 협상에 정상 참여하면서, 자기에게 정당하게 보이는 메시지만으로 타인의 선호를 추정하는 참여자. 외부 도청자는 암호화 채널(FR — CFR-G1)의 소관이라 여기서 다루지 않는다 |
| **관점(viewpoint)** | ① **일반 참여자 관찰자** — 판정 기준. ② **Blackboard 담당자** — 병기. 담당자는 구조상 더 많이 보므로 따로 재야 "노출이 사라진 것인지, 한 곳에 몰린 것인지"가 드러난다 |
| **역추론 이득 (gain)** | 공격자의 1순위 후보 추정 정확도 − 무작위 추측 기대 정확도(후보 M개면 1/M). 후보 수와 무관하게 "관찰이 실제로 흘린 정보량"만 잰다 |
| **최대 이득** | 완전 노출 시의 이득 = 1 − 1/M. 유출의 상한 (수학값) |
| **정규화 노출률** | 이득 ÷ 최대 이득 — 0(무유출)에서 1(전면 노출) 사이의 유계 값 |

## 29.3 핵심 지표 — 정규화 노출률과 별점 척도

> **지표**: 고정된 frequency 공격자(§29.4)가 일반 참여자 관찰자 시점에서 타인들의 1순위를 추정한 **정규화 노출률** (낮을수록 좋음). Blackboard 담당자 시점의 값을 병기한다.

**별점 척도** — 노출률은 0(무유출, 수학적 하한)과 1(전면 노출, 수학적 상한) 사이의 유계 값이므로, 구간 전체를 별점 단계 수(6)로 등분한다. 앵커 둘 다 수학값이라 임의 상수가 없다:

| 별점 | 정규화 노출률 | 뜻 |
|---|---|---|
| **5점** | 1/6 이하 | 사실상 무유출 — [`21`](21-핵심-QA-측정-정의.md)의 참고선(이득 +10%p, M=12 기준 노출률 0.11)이 이 구간에 들어온다 |
| **4점** | 1/6 - 2/6 | |
| **3점** | 2/6 - 3/6 | 관찰 누적 시 실용적 추정 가능 |
| **2점** | 3/6 - 4/6 | |
| **1점** | 4/6 - 5/6 | |
| **0점** | 5/6 초과 | 사실상 전면 노출 — 관찰자가 타인의 1순위를 그냥 안다 |

## 29.4 공격자 — frequency 상대 모델 (고정·봉인)

- **기법**: frequency 계열 상대 모델링(opponent modeling) — "이르게/자주 제안·수락된 것일수록 선호가 높다"는 원리로, 점수 없이 패턴만으로 선호를 추정하는 자동 협상 분야의 표준 공격이다.
- **구현 방식의 변경 (정직하게)**: [`21`](21-핵심-QA-측정-정의.md)은 NegMAS `FrequencyUFunModel` 클래스를 지정했으나, 그 클래스는 NegMAS SAO/GB 메커니즘의 콜백에 결합되어 있어 자체 프로토콜([`51`](51-설계후보1-다자-합의-프로토콜.md))에는 직접 꽂을 수 없다. 따라서 **동일 원리를 관찰 이벤트 위에 재구현**하고 규칙을 코드에 고정·명문화했다 ([`poc/dp2-nparty/src/dp2_nparty/measures/confidentiality.py`](../../poc/dp2-nparty/src/dp2_nparty/measures/confidentiality.py)) — "공격자 고정·봉인" 요구는 이 명문화로 충족한다.
- **고정 규칙**: ① 피해자의 제안이 보이면 가장 이른 (바퀴, 라운드)의 제안을 1순위로 추정 ② 제안이 안 보이면 가장 이른 바퀴에 O를 준 후보로 추정 ③ 아무 신호도 없으면 무작위 추측(기대 정확도 1/M로 계산).
- 공격자를 바꾸면 대안 간·시점 간 비교가 무너진다 — 변경 시 전 측정 재실행.

## 29.5 측정 방법

1. 선호 프로파일을 무작위 생성한 협상 100회 실행, 세션의 관찰 이벤트 기록.
2. 관점별 가시 이벤트 필터 적용 — 각자가 정당하게 보이는 것만 공격자 입력으로: 방안 1은 라운드 후보 공지·공개된 O/X, 방안 2의 일반 참여자는 자기 제출뿐.
3. 공격자가 관찰자 외 전원의 1순위를 추정 → 정확도 → 이득 → 정규화 노출률 → 별점.
4. 일반 참여자 관찰자로 판정하고, Blackboard 담당자 값을 병기한다.

## 29.6 측정 목표

- **참고 목표: 일반 참여자 관찰자 기준 별점 5점** (노출률 1/6 이하 — 21의 +10%p 참고선 포함 구간). 비핵심 QA이므로 이 목표는 **합격선이 아니라 감시선**이다 — 미달해도 설계를 기각하지 않고, 수치를 기록해 리스크로 보고한다 ([`23`](23-핵심-QA-최종-확정.md) §23.3의 강등 방침).
- **담당자 관점의 해석**: 담당자 노출률이 1에 가까운 것은 구조상 자연스럽다 — 중요한 것은 "참여자 간 노출이 낮은 대안일수록 정보가 담당자에게 집중된다"는 이동을 명시적으로 기록하는 것이다 (담당자 신뢰 전제).

- 역추론을 구조적으로 차단하는 설계의 선택 — [`33`](33-정보-공개-구조.md)의 소관 (본 축은 그 결과를 재는 자)
