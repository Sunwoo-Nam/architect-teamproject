## 1. 표기 정정 — 51 문서 원문과의 불일치

51 §3(방안 1) 원문에는 "(참고 관찰 — Confidentiality는 비핵심)"이라는 주석이 있다. 이는 23 문서의 상향 조치(2026-08-12) **이전** 상태를 반영한 것으로, 현재는 최신이 아니다.

> "Confidentiality | 2위 | **핵심 5위** | 비핵심 7위였다가 2026-08-12 PL 지시로 상향 — 사용자 선호 노출 우려 복원 + 전 N 실측에서 구조 간 차이가 크게 갈림" — [`23-핵심-QA-최종-확정.md`](../23-핵심-QA-최종-확정.md) §23.2

51 원문의 이 주석을 수정하는 것은 본 요청(다이어그램 뷰 제안) 범위 밖이라 이 문서에서는 손대지 않았다 — 별도 승인 후 처리가 필요한 항목으로 남긴다.

## 2. QA 정의 — 무엇을 측정하는가

> "협상 메시지의 관찰만으로 타 참여자의 선호 순위를 복원할 수 있는 정확도를 무작위 추측 수준까지 최소화해야 한다" — [`20-핵심-QA-확정.md`](../20-핵심-QA-확정.md) QA-CF-2

측정은 "각자가 정당하게 보는 관찰만으로 타인의 선호를 역추론"하는 공격 실험이다 — 이 문서가 그릴 "누가 무엇을 보는가" 구조가 그 공격의 입력 자체다.

## 3. 방안 1-A의 노출 구조

> "재배포가 익명이라 일반 참여자는 남의 귀속을 보지 못하고 O/X도 못 본다(방안 1은 공유 게시판이라 전면 노출). 대신 담당자 1인이 전 제출 + 전 O/X를 본다 — 노출 지점이 담당자에게 집중된다." — `protocol_styles.py` `Plan1aSao` docstring, 51 §3-1

- 일반 참여자 P1…P(N-1): 배포되는 후보 목록은 익명(제안자 불명) — 누가 무엇을 냈는지 모른다. 다른 참여자의 O/X도 못 본다.
- 담당자 P0: 모든 수집·모든 회신(O/X 묶음 + 다음 후보, [`51-3`](51-3-메시지페이로드-구조-검토.md) 참고)을 직접 받는다 — 전원의 판정과 제안 이력을 전량 보유.

## 4. 방안 2의 노출 구조

> "노출되는 것은 제안뿐이다 — 명시적 수락/거절 신호가 없다." — 51 §4 특성

참여자 간 노출은 1-A와 마찬가지로 없다(제출은 담당자 단말만 받는다 — 51-1 §1에서 정정한 대로 "Blackboard"는 담당자 단말 자신이다). 담당자는 전원의 누적 제출 집합을 보유하지만, O/X라는 판정 신호 자체가 방안 2에는 없다 — 제출 여부(=수락 의사)만 노출된다.

## 5. 대비 표

| | 방안 1-A | 방안 2 |
|---|---|---|
| 참여자 간 노출 | 없음 (재배포 익명) | 없음 |
| 담당자가 보는 것 | 전 제출 + 전 O/X (판정 신호 포함) | 전 제출 (제출=수락 의사, 판정 신호 없음) |
| 담당자 관점 역추론 재료 | 더 많음 — O/X로 문턱 근처 추정 가능 | 더 적음 — 제출 여부만 |
| 일반 참여자 관점 역추론 이득 | 0 (방안 1 대비, 51 §3-1) | 0 |

## 6. 실측 코드와의 일치 확인 — `measures/confidentiality.py`

이 구조 서술이 추측이 아니라 실제 측정 코드의 관점(viewpoint) 모델과 일치하는지 확인했다.

> "공격자: frequency 계열 상대 모델 ... 관찰된 제안·수락/거절 신호의 빈도·시점으로 상대의 선호 상위 후보를 추정" — `measures/confidentiality.py` 1-9행

> "participant(일반 참여자 관찰자): ... 방안 1-A → 게시판이 없고 재배포가 익명 후보 목록이라 귀속을 못 본다. O/X도 담당자에게만 가고 결과 공지가 없어, 참여자 관점은 방안 2와 같은 무신호다. 방안 2 → 참여자 간 배포가 없어 남의 제안·의견을 전혀 보지 못한다. / coordinator: 세 방안 모두 전체 제출을 본다. 방안 1·1-A는 O/X까지 본다." — 같은 파일 11-18행

측정 지표: "1순위 후보 추정 정확도 − 무작위 기준선(1/후보 수) = 이득(%p)"(같은 파일 20행) — 이것이 23 문서가 말하는 "정규화 노출률"이다. 즉 §3-5의 구조 서술은 이 실측 코드의 관점 모델과 그대로 일치하며, 이 문서에서 새로 도출한 내용이 아니다.

## 7. 다음 그림에 반영할 요소

1. 노출 경로를 화살표 굵기/색으로 구분한다(참여자간=없음, 담당자→전량).
2. Confidentiality 핵심 5위 상향 사실을 그림 상단에 명시하고, 51 원문 주석과의 불일치를 각주로 표시한다.
3. "구조도이며 `measures/confidentiality.py`의 실측값(정규화 노출률)은 별도"라는 점을 명시한다.
4. 참여자 관점(무신호, 두 방안 동일)과 담당자 관점(정보량 차이 있음)을 별도 트랙으로 그린다.
