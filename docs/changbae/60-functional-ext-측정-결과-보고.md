## 0. 핵심 요약 (보고용 — PPT 1-2장 분량)

**측정 대상**: 다자간 협상 프로토콜 두 설계안 — **방안 1-A**(SAO 투표형: 라운드마다 각자 후보 1개 제안, 만장일치 O가 나온 첫 후보로 즉시 합의)와 **방안 2**(BlackBoard 순위 수집형: 전원 제출 완료를 기다려 순위 종합이 가장 좋은 후보로 합의).
**측정 판**: functional-ext — 참여자 3-50명 8레벨 × 유형 5종 × 12건 = **480케이스** 전수 (QA는 nparty 분업분인 FC·CF·TB 3종).

| QA (판정 지표) | 방안 1-A | 방안 2 | 우세 |
|---|---|---|---|
| **FC** 달성률 = U(도달)÷U(최적) | 0.866 **★3** | 0.959 **★5** | **방안 2** — 전 N 레벨 ★5 고정 |
| **CF** 잔여 비밀률 (끝까지 비밀로 남는 내 선호 비율, 합의 세션 기준) | 75% **★4** | 50% **★3** | **방안 1-A** — 1:1 협상 수준(75%) 유지 |
| **TB** 시간 비율 ρ (naive 대비) | 0.147 **★5** | 0.171 **★5** | 동급 (둘 다 naive의 15-17%) |

**세 줄 결론**:

1. **정확성은 방안 2의 압승** — 케이스 승패 273 : 15 (무승부 192). 방안 1-A는 "빨리 닫히는" 구조 탓에 총효용 낮은 미끼 후보에 조기 합의하며, 이 손실은 인원이 많을수록 커진다 (N=3 ★4 → N≥15 ★2, 달성률 0.925 → 0.833).
2. **기밀성은 방안 1-A 우위** — 합의가 된 협상 기준, 1-A는 선호(전체 12후보 서열)의 75%가 비밀로 남아 **1:1 협상의 실측 잔여(75%)와 같은 수준**이지만, 방안 2는 50%에 그친다. 방안 2의 성립 규칙(전원 제출 대기)은 합의 후보를 가장 낮게 평가하는 사람의 순위까지 전원을 끌고 내려가기 때문이다. 수락 가능 목록 기준으로 보면 방안 2는 합의 판에서도 피해자 42%가 낼 수 있는 패를 전부 깐다.
3. **시간은 둘 다 우수** — naive 프로토콜(전 후보 순차 제안) 대비 15-17%로 동급 ★5. 즉 **이 판의 승부처는 FC(방안 2) vs CF(방안 1-A)의 트레이드오프**다.

**결렬 판별은 양쪽 모두 완벽**: 정답이 결렬인 96케이스에서 두 방안 다 96/96 정확히 결렬 (억지 합의 0건).

## 1. functional-ext 데이터셋 구성

### 1.1 개요

| 항목 | 값 |
|---|---|
| 총 케이스 | **480건** = 8레벨 × 60건 |
| 참여자 수 N | 3 / 5 / 7 / 10 / 15 / 20 / 30 / 50 (레벨당 60건 균등) |
| 후보 수 | 12개 고정 (S01-S12) |
| 유형 | 5종 × 레벨당 12건 (아래 §1.2) |
| 공통 유효 후보 K | 유형별 0-4개 **의도 배치(planted)** — 실측 검산 480/480 일치 |
| threshold | 참여자별 0.30-0.55 풀에서 배정 (케이스의 40%는 전원 동일 0.40) |
| 저장 위치 | [`poc/total/datasets/nparty/functional-ext/`](../../poc/total/datasets/nparty/functional-ext/) (`FX-<NN>p-<seq>-<유형>.json`) |
| 생성기 | [`generate_functional.py`](../../poc/total/scripts/generate_functional.py) — 기존 functional 생성기를 **수정 없이** 재사용, 레벨별 시드 20260813+N (재현 가능) |

기존 functional 트랙(3·5·7인 160건)의 **컨셉을 그대로 상속**하고 N 레벨과 표본 수만 확장했다. 기존 160건은 원 위치에 보존되며 판정에는 쓰지 않는다 (24 §1.5).

### 1.2 유형 5종 — 각 판이 검증하는 것

| 유형 | K | 구성 | 검증 목적 |
|---|---|---|---|
| wide_common | 4 | 전원 수락 가능한 상위 후보 여러 개 + **미끼** | 선택지가 많을 때 최적을 고르는가 |
| single_common | 1 | 전원 바닥선을 넘는 실후보가 하나뿐 | 유일해를 찾아내는가 (정답 유일 → 변별 없음) |
| utility_tradeoff | 3 | 유효 후보 간 총효용 격차가 큼 (bimodal) + 미끼 | 어느 것으로 닫히는지가 크게 갈리는 판 |
| bottleneck_participant | 2 | 한 명의 높은 바닥선(0.70)이 유효 영역 제한 + 미끼 | 병목 참여자가 있어도 최적에 도달하는가 |
| no_deal_optimal | 0 | 전원 바닥선을 넘는 실후보 없음 | **결렬이 정답**일 때 억지 합의를 안 만드는가 |

### 1.3 미끼(decoy) 구조 — 이 데이터셋의 핵심 장치

무작위로 utility를 뿌리면 최적 후보 x\*가 대체로 전원의 상위권이라 어떤 방안이든 x\*에 도달해 버린다 (기존 파일럿에서 판별율 10% 확인). 그래서 **역방향 구성**을 쓴다: "총효용은 낮지만 한 참여자에게만 1순위인 실후보(미끼)"를 심는다.

- **빨리 닫히는 방안**은 미끼가 첫 라운드에 만장일치 O를 받아 그것으로 합의 → 달성률 하락.
- **기다리는 방안**은 전원 제출까지 대기해 총효용 최대 x\*로 합의.
- 단, 미끼 3유형의 절반은 **plan2-miss 변형** — 방안 2도 x\*를 놓치도록 순위 깊이를 조작해, 표본이 어느 한쪽의 우세를 구조적으로 보장하지 않게 한다 (§5.3에서 실효 확인).

x\*의 순위 깊이는 early(2-3위)·middle(4-7위)·late(8-10위) 3밴드를 유형 안에서 순환 배치해 깊이 편향을 막는다.

### 1.4 utility 분포 특성 (실측)

- 후보별 utility를 직접 무작위 추출 → **0-1 거의 균등 분포** (평균 0.479, 표준편차 0.295). 0.9 이상 후보가 11%로 "뚜렷한 최적"이 존재하는 판이다.
- 개인 유효 비율(자기 threshold 이상 후보 비율) 중앙 50% — "깐깐한 개인"의 판.
- 대비: main 트랙(의제 가중합)은 종형 분포(표준편차 0.164)·개인 유효 87%로 "관대한 현실 모사" 판이다. **functional-ext는 변별 극대화, main은 현실 모사**로 성격이 상보적이다.

## 2. 측정 방법 요약

- **QA 분업**: nparty 시나리오는 **FC·CF·TB** 3종을 담당한다 (RU·SC-의제는 composite 시나리오 담당 — PL 확정 2026-08-13). 판정 지표·별점 사다리는 전부 [`24`](24-QA-측정-핸드북.md) §0.
- **FC 판정 = 달성률** (2026-08-13 재개정): 별점 사다리 ≥0.95 ★5 / ≥0.90 ★4 / ≥0.85 ★3 / ≥0.80 ★2 / ≥0.70 ★1. 보조 s ≤ 0(무작위 이하)이면 별점과 무관하게 즉시 결함.
- **CF 판정 = 잔여 비밀률** (2026-08-13 재개정): 협상 종료 시 나를 가장 많이 아는 관찰자에게도 공개되지 않고 남은 **내 선호의 비율 (분모 = 전체 후보 12개)**. **모수 = 합의 완료 세션만** (결렬의 전량 노출은 방안 무관 본성 — 합의율 80%를 병기, 두 방안 동일). 별점은 무노출 100%-전량 공개 0% 사이 20%p 등분. 1:1 협상 실측 잔여 75%(e₂ = 0.25)는 ★4 구간의 병기 참조점. 보조로 노출 배수 m(관찰자 폭) 병기.
- **TB**: ρ = T_설계 ÷ T_naive. naive = 다자 SAOP round-robin (1명씩 제안·전원 회신). T는 합성 모델 (phase 75ms + 평가 1.4µs + 전송 20Mbps — 24 §4.4).
- **실행**: `experiments/nparty_tracks.py --tracks functional-ext`, 480건 × 2방안 전수 **22.5초**. 결정론(시드 고정)이라 재실행 시 동일 값.

## 6. 분포·경계 관측

- **달성률 분포가 두 방안의 성격을 보여준다** (미끼 3유형 288건 기준): 방안 2는 **이봉** — 204건이 만점 1.0이고 실패 시 0.5-0.7로 떨어진다 (전부냐 아니냐). 1-A는 0.5-0.95에 **넓게 퍼진다** (미끼의 품질만큼 얻는다).
- **1-A의 케이스 단위 s < 0이 172건(36%)** — 셋 중 하나 이상의 판에서 무작위 선택 기대값보다 나쁜 결과를 냈다. 표본 평균 s는 0.041로 결함선(≤0) 위에 있으나 근소하다.
- **degenerate(R̄=1) 케이스 96건** = no_deal 전건. 양쪽 다 정확히 결렬이라 판정 왜곡 없음.
- **TB 결함 1건**: `FX-03p-059-bottleneck-participant`에서 방안 2의 ρ = 1.00 (naive와 동급). N=3 소인원 + 병목 참여자 조합에서 방안 2의 대기 비용이 naive의 순차 제안과 같아진 경계 사례다. 1-A는 결함 0건.

## 8. 한계와 남은 결정

1. **미끼 판의 인공성**: functional-ext는 "빨리 닫히는 방안의 최악 구도"를 의도적으로 심은 변별 극대화 판이다. 무작위 현실 모사 판(main 트랙, 700건)에서는 두 방안의 FC가 백중(0.563 vs 0.553 s 기준)이었다 — 보고 시 "1-A는 평균적 판에서는 대등하나 적대적 구도에서 무작위 이하로 붕괴하며 그 취약성이 N에 비례한다"로 함께 읽는 것이 정직하다.
2. **FC 별점 사다리는 잠정** (★1만 0.70-0.80의 10%p 구간). R̄ = 0.86인 판이라 무작위도 ★3권을 받는 한계가 있으며, 방어 장치는 s ≤ 0 즉시 결함 규칙과 R̄·s 병기다.
3. **CF 판정은 잔여 비밀률로 확정** (2026-08-13 재개정 — 분모 = 전체 후보, 모수 = 합의 세션) — 구 배수 m에서는 두 방안이 같은 ★2로 뭉개졌으나 75% ★4 vs 50% ★3으로 갈린다. 결렬 세션(20%)은 어느 방안이든 전량 노출이 본성이라 모수에서 제외하며, 그 대신 합의율(80%, 두 방안 동일)을 병기한다. 보조 관측: 수락 가능 목록 기준으로는 방안 2 피해자의 42%가 합의 판에서도 낼 수 있는 패를 전부 깐다.
4. RU·SC-의제는 composite 시나리오 담당분이라 본 보고에 없다 — composite 정본 측정과 합치면 핵심 QA 5종 완결.
