# 10. 핵심 QA 측정 계획 — 지표·목표 수준·테스트 환경·방법

> 대상: [`08`](08-핵심-QA-중요도-난이도-평가.md) §8.3에서 선정한 **최우선 QA 11종** + 별도 품질 지표 **효용 분배 균형**.
> 각 QA에 대해 ① 무엇을 재는가(지표·산식), ② 어떤 수준을 만족해야 하는가(목표), ③ 어디서 어떻게 재는가(환경·방법)를 정의한다.
> 모든 지표·목표는 **분석자 제안**이며 팀 합의·베이스라인 실측을 거쳐 확정한다. QAS(품질 속성 시나리오) 작성 시 본 계획의 각 행이 "자극 → 환경 → 응답 측정"의 원천이 된다.

---

## 10.1 목표 수준의 두 유형

| 유형 | 의미 | 표기 |
|---|---|---|
| **절대 기준** | 결정적으로 검증 가능한 요구 — 실측으로 조정하는 값이 아니라 위반 자체가 결함 | **0건 / 100%** |
| **파일럿 목표** | 통계적 요구 — 베이스라인 실측 전의 잠정 목표. 1차 실측 후 확정치로 대체 | *(제안)* 표기 |

## 10.2 테스트 환경 정의

| 환경 | 구성 | 담당 CFR | 용도 |
|---|---|---|---|
| **ENV-A: Mock 다자 시뮬레이션** | Mock 참여자 N명(스크립트된 선호·threshold·응답 지연) + 기록·재생 하니스(입력·난수·LLM 응답 고정) + 장애 주입기(이탈·단절·타임아웃·메시지 손실) | CFR-J2·J8·J3 | 프로토콜 로직·신뢰성·정확성 계층의 대량 반복 실험 — **다자 검증의 기본 환경** |
| **ENV-B: 실기기** | Galaxy 단말 1~3대 + Android 프로파일러(메모리·CPU·배터리)·adb(Doze 강제 진입·저메모리 시뮬레이션) + 온디바이스 LLM 실추론 | CFR-I13·J4 | 시간·자원·OS 공존 등 단말 물리 특성이 지배하는 QA — 시뮬레이션으로 대체 불가한 항목 |
| **ENV-C: 사용자 평가** | 소수 실사용자 또는 페르소나 기반 Mock 판정기(선호 프로파일로 승인/수정/거부를 판정) | CFR-J4·J9 | 통계 계층(의도 정확성 L1·선호 정합 L3)의 수용성 판정 — 최종 판정 주체가 사용자인 항목 |

> 원칙: **로직은 ENV-A에서 대량으로, 물리는 ENV-B에서 소수 정밀하게, 수용성은 ENV-C에서** 잰다. 시간 예산처럼 둘이 결합되는 항목은 "ENV-A의 라운드 수 × ENV-B의 실측 추론 시간"으로 합성한다 (분석자 제안).

## 10.3 최우선 QA 11종 측정표

### 1. Functional Correctness (기능 정확성) — 4계층별로 분리 측정 ([`09`](09-Functional-Correctness-정의.md))

| 계층 | 측정 지표 (산식) | 목표 수준 | 환경 | 테스트 방법 (자극 → 측정) |
|---|---|---|---|---|
| 의도 정확성 (L1) | 분류 정확도 = 올바르게 감지된 의도 / 라벨된 전체 케이스, 오탐률 = 의도 없는 대화에서 협상 개시된 비율 | 정확도 ≥ 90%, 오탐률 ≤ 5% *(제안 — 베이스라인 실측 후 확정)* | ENV-A + 라벨 데이터셋 | 그룹 대화 스크립트(의도 있음/없음 라벨) N건 주입 → 감지 결과를 라벨과 대조 |
| 제약 준수 (L2) | 합의안·발신 제안의 제약 위반 건수 (참여자별 위임 범위·캘린더 충돌·예산·공유 금지 대조) | **위반 0건 (절대)** | ENV-A | 무작위 선호·제약 조합으로 협상 M회 실행 → 전 제안·합의안을 규칙 검사기로 전수 대조. **경계값 케이스**(예산 상한 ±1, threshold 경계의 위임 밖 후보) 필수 포함 |
| 선호 정합 (L3) | 무수정 승인율 = 제시안을 수정 없이 승인한 비율, 수정률·거부율·재협상 요구율 | 무수정 승인율 ≥ 70% *(제안 — 1차 실측을 베이스라인으로 확정)* | ENV-C | 페르소나 선호 프로파일로 협상 실행 → Mock 판정기/실사용자의 승인·수정·거부 기록. 선호 입력 누락 오류를 의도 주입한 대조군으로 지표 민감도 확인 |
| 합의 종결 정합 (L4) | 종결 시점 확정 당사자 간 합의 레코드 불일치 건수 + 미승인자 효력 발생 건수 | **불일치 0건 + 미승인자 효력 0건 (절대)** | ENV-A | 커밋 단계(ACK 수집 중)에 단절·이탈을 주입한 협상 M회 → 종료 후 전 참여자의 최종 레코드를 기계 대조 |

### 2~11. 나머지 10종

| QA | 측정 지표 (산식) | 목표 수준 | 환경 | 테스트 방법 (자극 → 측정) |
|---|---|---|---|---|
| **Fault Tolerance** (결함 감내) | 장애 주입 케이스 중 협상이 정상 완결(합의 또는 정상 결렬)된 비율, 일시 오류의 자동 복구율 | 일시 오류(메시지 손실·지연·LLM 타임아웃) 주입 시 완결률 ≥ 95% *(제안)*, 단일 참여자 이탈 시 잔여 그룹 지속률 100% (완결 규칙상 지속 가능한 케이스 기준, **절대**) | ENV-A | 라운드 진행 중 무작위 시점에 장애 유형별(손실/지연/무응답/이탈) 주입 → 세션 최종 상태(완결/불확정)를 분류. 불확정 상태 발견 = Fail Safe 결함으로 별도 기록 |
| **Scalability** (확장성) | N ∈ {3, 5, 7}에서의 합의 시간·라운드 수·메시지 수·메모리 — N에 대한 증가 함수의 회귀 적합 | 참여자 축: 선형 이내 증가 *(제안 — 초선형이면 프로토콜 재설계 신호)*. 의제 축: 의제 수 2~4에서 메모리 상한 초과 **0건 (절대)** | ENV-A (로직) + ENV-B (자원 확인) | 동일 시나리오를 N과 의제 수만 바꿔 반복(각 조합 M회) → 지표를 N에 대해 회귀 분석. 가지치기(CFR-B12) on/off 비교로 탐색 공간 축소 효과 정량화 |
| **Time Behaviour** (시간 효율성) | 합의 도달 총 시간 = 라운드 수(ENV-A) × 라운드당 실측 시간(ENV-B: 온디바이스 추론+통신), 개입 반영 지연 | 3인 일정 합의 기준 총 5분 이내 *(제안 — 실기기 추론 시간 실측 후 라운드 예산으로 환산·확정)* | ENV-A × ENV-B 합성 | 시뮬레이션으로 라운드 수 분포 수집 + 실기기에서 라운드 1회의 추론·전파 시간 실측 → 곱으로 총 시간 추정, 대표 케이스는 실기기 E2E로 검증 |
| **Recoverability** (복구 가능성) | 세션 복구 성공률 = 중단 후 재개 성공 / 복구 시도, 복구 후 상태 불일치 건수, 재동기화 시간 | 복구 성공률 ≥ 95% *(제안)*, 복구 후 상태 불일치 **0건 (절대)** | ENV-A (+ ENV-B에서 OS 강제 종료 케이스) | 임의 라운드에서 프로세스 kill·네트워크 완전 단절 → 재시작 후 세션 재개 여부·전 참여자 상태 일치·소요 시간 측정 |
| **Testability** (시험 용이성) | Mock 재현 커버리지 = 정의된 시나리오·이상 카탈로그 중 ENV-A에서 재현 가능한 비율, 재생 재현율 = 동일 기록 재생 시 동일 결과 비율 | 커버리지 **100% (절대)**, 재생 재현율 **100% (절대)** | ENV-A 자체 검증 | 시나리오·이상 카탈로그 전 항목을 Mock으로 실행 시도 → 불가 항목 목록화(=구조 결함). 기록된 세션을 2회 재생 → 결과 diff |
| **Resource Utilization** (자원 효율성) | 피크 메모리·참여자당 메모리 증가분·옵션 공간 표현 메모리·협상 1회당 배터리 소모 | 단말 프로파일별 메모리 예산 내 · OOM **0건 (절대)** · 참여자당 증가분 선형 *(제안 — 예산 절대값은 단말 사양 실측 후 확정)* | ENV-B | N·의제 수 스윕하며 프로파일러로 계측. 전체 열거 대비 가지치기 적용의 메모리 절감을 대조 실험으로 확인 |
| **Confidentiality** (기밀성) | 공유 금지 정보의 그룹 노출 건수, 참여자별 차등 공개 정책 위반 건수, 역추론 성공률(공격자 모델이 메시지 로그에서 타 참여자 선호 순위를 복원하는 정확도) | 노출·정책 위반 **0건 (절대)**, 역추론 성공률은 무작위 추측 수준으로 **최소화** *(제안 — 공격자 모델 정의 후 확정)* | ENV-A + 메시지 검사기 | 협상 전 메시지 로그를 정책 스캐너로 전수 검사. 별도로 역추론 공격자 모델(로그만으로 선호 복원 시도)을 실행해 복원 정확도 측정 |
| **Operational Constraint** (운용 제약 준수) | 위임 범위 초과 행동 건수 (수락·집계·확정·인계 전 경로), 미승인자 확정 효력 건수 | **초과 0건 + 미승인자 효력 0건 (절대)** | ENV-A (적대적 케이스) | threshold는 넘지만 위임 범위 밖인 고효용 후보를 의도적으로 생성·주입 → 이중 검사(CFR-C2)의 차단 여부 확인. 완결 규칙별(전원/다수결/부분)로 미승인자 효력 검사 반복 |
| **Co-existence** (공존성) | Doze 진입 중 세션 생존율, OS 강제 종료 빈도, 포그라운드 앱 성능 저하(프레임 드랍) | Doze 통과 세션 생존율 ≥ 95% *(제안)* — 강제 종료된 세션의 복구는 Recoverability로 이관 측정 | ENV-B | 협상 진행 중 adb로 Doze 강제 진입·저메모리 상황 유발·포그라운드 부하 앱 실행 → 세션 상태·OS 이벤트 로그·프레임 지표 수집 |
| **Operability** (운용성/사용자 통제) | 개입 반영 지연 = 개입 명령 시점 → 협상 상태 반영 시점, 승인 없는 확정 건수 | 개입 반영 ≤ 1라운드 경계 *(제안 — 설계 질문 6의 개입 시점 모델 확정과 연동)*, 무승인 확정 **0건 (절대)** | ENV-A | 임의 라운드에 스크립트된 개입(중단·조건 변경·거절) 주입 → 반영 시점·전 참여자 상태 일관성 확인 |
| **Analysability** (분석 용이성) · **Accountability** (책임 추적성) — 기반 QA | 이력 완전성 = 무작위 협상의 모든 상태 전이가 로그에서 재구성 가능한 비율, 참여자별 행위 귀속 정확도 | 재구성 가능률 **100% (절대)**, 귀속 오류 **0건 (절대)** | ENV-A | 완료된 협상 M건에서 로그만으로 "왜 이 합의인가"의 라운드별 인과를 재구성하는 감사 시뮬레이션 → 재구성 불가 지점 목록화 |

## 10.4 별도 품질 지표 — 효용 분배 균형 (Utility Distribution Balance)

| 항목 | 내용 |
|---|---|
| 측정 지표 | 단일 협상: 확정 합의안의 참여자별 효용 분포(최소 효용·분산). 반복 협상: 동일 그룹 반복 실행에서 참여자별 누적 효용·1순위 채택률의 편향 추세 |
| 목표 수준 | 특정 참여자의 체계적 우위가 통계적으로 유의하지 않을 것 *(제안 — 구체 지표·유의 기준은 팀 결정, [`09`](09-Functional-Correctness-정의.md) §9.7)* |
| 환경·방법 | ENV-A — 동일 선호 구성을 역할만 바꿔(개시자 로테이션) 반복 실행 → 역할·양보 속도에 따른 효용 편향을 대조. 완결 규칙(전원/다수결/부분)별로 비교해 CFR-B9 설계 입력으로 사용 |

## 10.5 운용 원칙·미결정

1. **측정의 전제**: 본 계획의 전 항목은 ENV-A(Mock·기록 재생)의 성립을 전제한다 — 시험 용이성(Testability)이 자체 절대 기준(커버리지·재현율 100%)을 갖는 이유다.
2. **QAS 연계**: QAS 작성 시 각 행을 "자극(주입 이벤트) → 환경(ENV-A/B/C) → 응답 측정(지표·목표)"으로 전개한다.
3. **미결정** (팀 논의): ① *(제안)* 표기 목표치의 확정(베이스라인 실측 후), ② 역추론 공격자 모델의 정의, ③ 효용 분배 균형의 구체 지표, ④ L1 라벨 데이터셋의 구축 주체·규모.
