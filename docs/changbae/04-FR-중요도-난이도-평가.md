# 4. Functional Requirements 중요도·난이도 평가 (CFR 64건, H/M/L) — 다자간 협상 범위

> 대상: [`03-FR-카테고리-정리.md`](03-FR-카테고리-정리.md)의 통합 FR **64건 전체** (원 항목 100건 커버)
> 모든 등급은 **분석자 판단**이며 근거를 병기한다.

---

## 4.1 평가 척도 정의

**중요도 (이 기능이 이 과제에서 얼마나 중요한가)**

| 등급 | 기준 |
|---|---|
| H | ① 다자 협상의 성립·수렴·검증에 직결, ② 온디바이스 실행 전제에 직결, ③ 사용자 위임의 전제(신뢰)에 직결, ④ PL 명시 지정 사항에 직결 — 없으면 과제가 성립하지 않음 |
| M | 완성도·특정 stakeholder 만족에 기여하나 대체·단순화·연기 가능 |
| L | 축소된 범위에서 생략 가능 |

**난이도 (구현·구조 난이도)**

| 등급 | 기준 |
|---|---|
| H | 미확립 설계 문제(다자 프로토콜·분산 상태·역추론 방어 등) 또는 전 경로를 관통하는 교차 기능 |
| M | 특정 모듈로 구현 가능하나 상당한 설계·구현량 필요 |
| L | 확립된 기술·패턴 적용으로 구현 가능 |

| CFR-B7 | threshold 수락/거절 판정 | H | M | 알고리즘의 판정 단계 / NegMAS 기제공 + 위임 범위 이중 검사(C2) 결합 필요 |
| **CFR-B8** | 양보(concession) 전략 | **H** | **H** | 수렴의 열쇠 — 양보 없이는 무한 루프, 과도하면 결과 품질 훼손 / 다자에서의 수렴 보장은 미확립 설계 |
| **CFR-B9** | 합의 완결 규칙 실행 (전원·다수결·부분 완결) | **H** | **H** | **2자→다자 확장의 핵심 신규 설계** — 시나리오별로 완결 규칙이 다름(전원 합의 / 정족수·다수결 / 승인자만 추려 완결 — PL 지시)을 모두 수용하면서 편향 없는 집계여야 함 / 미확립 문제 (분석자: 2자 NegMAS에는 없는 단계) |
| CFR-B10 | 결렬 판정·종결 | H | M | 불확정 상태 방지의 협상 측 절반 / 종결 조건 설계 — 상태 기계 완결로 해결 |
| **CFR-B11** | 중도 이탈·재참여 처리 | **H** | **H** | 다자 현실 조건 — N명 중 이탈은 상수적으로 발생 (시나리오 6 명시 문제) / 부분 진행·재동기화·합의 재검증이 얽힘 |
| **CFR-B12** | 제약 전파·후보 가지치기·지연 생성 | **H** | **H** | **PL 지목 관심사** — 다중 의제의 전체 조합(K×L×M×P)은 온디바이스 메모리에서 열거 불가(out of memory). 확정 의제가 미확정 의제의 후보 폭을 좁히는 구조를 다뤄야 협상이 성립 / 제약 전파·지연 생성 자체는 알려진 기법이나, **어느 의제부터 확정하는가(agenda)가 협상 프로토콜·결과 품질과 얽히는 부분**이 미확립 설계 |
