# DP 작성 가이드

## 공통 원칙
- 어떤 경우에도, 추상적이고 비유적인 표현을 사용하지 않는다.
- 형식은 [참고/DP_양식.md](DP참고/DP_양식.md)를 따르며, 섹션 구성을 변경하지 않는다.
- 전체 분량은 [참고/DP_양식.md](DP참고/DP_양식.md)와 유사한 수준으로 유지한다.

## 서술
- 각 후보안의 설명 섹션에는, 해당 후보안의 설계 내용을 독립적으로 설명한다. 다른 후보안과의 비교 내용을 넣지 않는다.
- 코드/변수명 등의 내용은 일반화된 용어로 설명한다. 필요한 경우 용어집에 추가한다.
- 내부 항목에 ID를 부여하지 않으며, 다른 문서나 세부 항목의 ID를 지칭하지 않는다.
